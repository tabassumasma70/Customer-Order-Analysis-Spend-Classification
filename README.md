# Customer-Order-Analysis-Spend-Classification
A Python data analysis project that structures customer order records, classifies buyers into spending tiers, calculates category revenue, and uncovers cross-category purchasing patterns.

## Project Overview and Objectives

This project processes and analyzes customer order records in Python to evaluate customer spending behavior, categorize products, and generate business insights. Its objectives are to structure order data cleanly, classify customers by spending tiers, calculate category-level revenue, and identify multi-category purchasing patterns.

## Technologies and Tools Used

* **Programming Language:** Python
* **Environment:** Jupyter Notebook
* **Core Python Concepts:** Lists, tuples, dictionaries, sets, loops, conditional statements, comprehensions, and set operations

## Key Features and Functionalities

* **Order & Catalog Structuring:** Maps customer names to ordered products, maps products to categories, and extracts unique product categories.
* **Customer Spend Classification:** Calculates total spend per customer and classifies buyers into **High-Value Buyer**, **Moderate-Value Buyer**, and **Low-Value Buyer** tiers.
* **Business & Revenue Insights:** Computes revenue per product category, lists unique products, identifies Electronics buyers, and ranks the top 3 spenders.
* **Cross-Category Set Analysis:** Uses set operations and intersections to find customers purchasing from multiple categories, including buyers of both Electronics and Clothing.
